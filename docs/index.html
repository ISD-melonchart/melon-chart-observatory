실행 중인 수집 작업이 다음 5분 구간의 작업을 자동으로 요청합니다. 사이트를 닫아도 계속 실행되지만, 실행 환경이나 원본의 제공 지연으로 구간이 누락될 수 있습니다. 사이트는 저장된 자료를 30초마다 다시 확인합니다.
