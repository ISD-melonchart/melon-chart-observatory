개인정보처리방침

차트 열람 과정에서 사용되는 정보와 외부 서비스의 처리를 구분하여 안내합니다.

시행일 · 2026년 11월 4일

회원가입 없이 이용하는 비공식 차트 기록 서비스입니다. 원본 콘텐츠의 권리는 각 권리자에게 있습니다.

1. 서비스가 직접 수집하는 정보

현재 CHART ROOM에는 회원가입·로그인·결제·댓글·알림 구독 기능이 없습니다. 차트 열람을 위해 이름, 이메일, 전화번호, 멜론 계정이나 비밀번호를 입력받지 않습니다.

곡·아티스트 검색은 현재 브라우저에 불러온 차트 안에서 처리하며, 검색어를 운영자에게 전송하거나 저장하지 않습니다. 자체 광고·방문자 분석 도구 및 추적용 쿠키·로컬 저장소를 사용하지 않습니다.

2. 저장하는 차트 기록

서버 측 수집 작업은 곡 ID·곡명·순위·공개 그래프·집계 감상자수와 원본 기준 시각을 저장합니다. 개별 멜론 이용자의 계정이나 재생 이력을 수집하지 않습니다. 차트 기록은 공개 GitHub 저장소와 사이트에서 제공되며 전일 비교 및 기록 열람에 사용됩니다.

3. 호스팅과 외부 이미지 요청

제공자발생할 수 있는 처리
GitHub Pages웹페이지와 JSON 파일을 제공합니다. GitHub는 보안을 위해 방문자의 IP 주소를 기록·보관한다고 안내합니다. 관련 처리는 GitHub의 정책에 따르며, 운영자는 GitHub의 보안 로그를 직접 제공받아 별도 보관하지 않습니다.
Melon 및 이미지 제공 서버앨범 이미지를 표시할 때 브라우저가 원본 이미지 서버에 직접 요청하므로 IP 주소와 브라우저 요청 정보가 전달될 수 있습니다. 사이트 주소가 참조 주소로 전달되지 않도록 referrer 정책을 설정합니다.

외부 제공자의 보관 기간·처리 위치·처리 기준은 각 제공자의 정책에 따르며 해외 서버에서 처리될 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침과 Melon 개인정보처리방침을 확인해 주세요.

4. 문의 게시판을 이용하는 경우

문의는 GitHub Issues에서 접수합니다. 문의를 등록하면 GitHub 계정명과 작성 내용이 해당 게시판에 공개될 수 있으며 GitHub의 정책이 적용됩니다. 전화번호·주소·계정 비밀번호 등 민감한 정보를 공개 게시물에 포함하지 마세요.

운영 계정은 ISD-melonchart입니다. 사이트의 정보 처리에 관한 질문이나 공개된 개인정보의 정정·삭제 요청도 이 경로로 전달할 수 있습니다. 운영자가 직접 처리하는 정보의 범위에서 요청을 확인하고, 외부 제공자에게 직접 요청해야 하는 사항은 해당 제공자의 개인정보 안내를 확인해 주세요.

5. 이용자의 선택과 방침 변경

브라우저에서 외부 이미지 로딩과 쿠키를 제한할 수 있습니다. 외부 이미지를 차단해도 텍스트 차트와 저장된 집계 수치는 열람할 수 있습니다.

향후 회원가입·분석·광고·알림 등 새로운 정보 처리가 추가되면 실제 변경 내용을 반영해 이 방침과 적용일을 안내하고, 법령에 따라 필요한 조치를 진행합니다.
