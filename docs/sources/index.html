데이터 출처·수집 기준

같은 시각의 기록을 정확히 비교할 수 있도록 원본 기준 시각을 보존합니다.

시행일 · 2026년 11월 4일

회원가입 없이 이용하는 비공식 차트 기록 서비스입니다. 원본 콘텐츠의 권리는 각 권리자에게 있습니다.

출처와 표시 항목

원본 출처는 Melon TOP100 및 공개 차트 화면입니다. 공개 웹 응답에서 확인되는 곡명·아티스트·앨범 이미지·차트 수치를 기록합니다. 본 사이트와 Melon 사이의 공식 제휴나 데이터 이용 허락을 의미하지 않습니다.

자료원본 기준과 해석
TOP100매 정각의 확정 순위 100곡입니다. 원본의 날짜·시각과 곡 수를 확인합니다.
HOT100 그래프5분 기준으로 제공되는 상위 5곡의 그래프 수치입니다. TOP100 전체 100곡의 그래프나 실제 감상자수와 동일한 값이 아닙니다.
실시간 감상자수원본의 10분 기준 시각을 확인해 곡별 집계 값을 기록합니다. 서로 다른 10분 구간의 이용자가 중복될 수 있어 합계를 일간 순감상자수로 사용하지 않습니다.
30·40·50분 예측각 회차에 원본이 제공한 다음 정각의 예상 순위를 별도로 기록합니다. 원본에 예측이 없으면 현재 공식 순위를 대신 넣지 않습니다.
전일 비교·리뷰같은 곡 ID와 전일 같은 시각의 기록이 함께 있을 때만 비교합니다. 일간 순감상자수 원본은 현재 미연결이며 해당 비교를 제공하지 않습니다.

자동 수집과 새로고침

수집 작업은 다음 5분 구간을 자동으로 이어 실행합니다. 원본 반영 시간을 고려해 구간 시작 후 약 12초부터 다음 작업의 실행을 요청합니다. 원본 갱신 대기나 일시적인 오류에는 1분 안에서 한 번 재시도합니다. 원본의 응답과 실행·배포 대기 때문에 화면 반영이 늦어질 수 있습니다.

방문자가 없어도 실행되며, 사이트는 저장된 자료를 30초마다 다시 확인합니다. ‘기록 새로고침’은 이미 저장된 자료를 다시 불러옵니다. 화면의 ‘자동 수집 지연’은 마지막 확인 이후 새 수집 시도가 오래 없는 상태를, ‘일부 자료 갱신 대기’는 수집을 시도했지만 일부 원본이 아직 확인되지 않은 상태를 뜻합니다.

누락과 변경 처리

실패·누락 자료는 0으로 바꾸지 않고 마지막 확인 자료의 실제 기준 시각을 유지합니다. 미수집 구간을 뒤늦게 현재 값으로 채우거나 예측하지 않습니다. 과거 원본이 수정되면 이미 저장된 기록과 달라질 수 있습니다.

원본 정보의 이용에는 Melon 이용약관과 각 권리자의 권리가 적용됩니다. 출처 표기만으로 복제·배포·상업적 이용에 대한 허락을 받는 것은 아닙니다. 문의는 운영 저장소로 전달할 수 있습니다.
